# 2026-08-23 — S2.1 G2.0 独立 evaluator

## 目标与范围

- 新增独立 G2.0 formal evaluator；输入限定为 `stage2.01_scope_hypotheses_and_preregistration` 的三个 formal TaskArtifact commit（`preregistration`、`hypothesis_contract`、`gate_record`）。
- 重读并重建预注册/H1–H6 合同，绑定冻结 plan、`docs/mathematics.md`、Stage 1 formal bridge/index/role closure、输入 config hash、evaluator producer commit/source hash 与 evaluation config hash；tracked `reports/...local_fixture` 不具正式权威。
- `data_root` 与 `repository_root` 显式分离：TaskArtifact/config/output 只从前者读取/写入，计划、数学/报告和 evaluator/validator/runner source 只从后者读取；所有边界拒绝路径逃逸和 symlink chain。
- 三个 S2.1 commit 的共同 `source_refs` 必须是四个 Stage1.11 formal TaskArtifact commit；重新加载其 task/kind/config/formal 身份、PASS 内容、core/task-definition bridge 和 binding hash，普通 JSON 不再被接受。
- 加载并校验持久化 `ResolvedConfigV2`（直接 wire ref 或 formal config TaskArtifact），将 task、formal、config/full hash 和 master-seed-derived seed plan 绑定到输入。
- runner 的 gate candidate 只接受 `NOT_RUN`、`formal_eligible=false` 作为“未自签”证明；不接受其数字或 PASS 状态。

## 证据身份与有效性

- evaluator output envelope 使用输入三 commit 的共同 `config_hash`，source_refs 按 canonical artifact-kind 顺序绑定三 commit；PASS 仅在 envelope 成功重新发现后暴露 `formal_eligible=true`。相同输入会先重读既有 envelope，复用原始 `checked_at`，不会因时间变化产生第二次 BLOCKED。
- 计划 hash 固定为 `9af31ee0b82cbb0526817c7bb741ca708e33f96e7be3dda65d54b188e942fe12`；数学文档 hash 从 prereg provenance 读取并核对当前 repository bytes，Stage1 身份只从 DATA_ROOT bridge/index/role hashes 重读。
- `evaluation_config_hash` 是完整 policy + 九个实际 tracked source hashes（含仅用于漂移审计的 local Stage1 report bytes）+ trusted HEAD 的 canonical hash，并写入 GateRecord measured/provenance；producer commit 必须存在，当前 HEAD 可直接通过，旧 ancestor 只有关键 evaluator/validator/runner/catalog/schema/plan/math/report bytes 全等才兼容；完整 porcelain worktree 必须 clean。
- 本机测试临时目录均位于 `.agent-temp/pytest/`，未产生仓库外临时证据。
