- `reference_sizing` 是独立 sizing stream；只有 sizing 收敛后才创建固定的 `OneShotReferencePlan`。
- final reference 严格消费独立的 `reference_A` 与 `reference_B` prefix，固定样本量、block 顺序和 draw identity；没有 optional stopping、replacement 或 synthetic fallback。
