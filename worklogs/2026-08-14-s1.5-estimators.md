## 任务边界

- 任务：`stage1.05_estimators`。
- 上游：S1.4 `G1-GRAD` 正式 index
  `evidence/stage1/s1-4-formal/92e3fa5ec286afa43c51be691895f9a7210199ff/formal-20260814-s14-v1-r1/index.json`；

- 目标：冻结 raw/raw-clipped、双采样、显式 ordered/unordered U、等权流式 U 与 token 加权流式 U 的纯张量合同，
  用独立 FP64 显式循环、充分统计量重放、边界负例及机器可读图表发布 `G1-EST`。
  本任务仅运行确定性 CPU fixture，不消费真实模型、数据集或 GPU。

## 实现与主代理验收

- 本任务由独立子代理使用 `gpt-5.6-terra`、`xhigh` 完成初始实现；主代理负责计划逐项反查、拒绝不完整版本并修正。
- 核心 API 增加严格 FP32/FP64、shape/device/registry、学习率组、clip factor 与累积 dtype 防线；
  双采样 provenance 冻结不同 batch 对象、sampler state、RNG stream/seed/state digest 和有放回 product-sampling 设计，
  同时明确允许样本 ID 偶然重合。
- 冻结真实 `ParameterRegistry` fixture：`bias` 与 `weight` 属于 `group_0000`，`head` 属于 `group_0001`；
  raw/double 输入为 global mean gradient，U 的统计单元为 local microbatch mean gradient，且进入估计器前梯度尺度已恢复。
- 每个 dtype profile 均发布 20 个独立比较对象：raw core/score/clipped、double core/score、ordered/unordered/streaming U、
  weighted U、等计数退化、`M=2` 与 double、A/B 交换、非零相同梯度退化、两种等权排列和两种样本—权重配对排列。
- 14 个精确拒绝项覆盖 `M=1`、同一 batch、共享 sampler、非有限/shape/registry/dtype/device、非正权重/分母、
  负或非有限学习率、非有限或越界 clip、FP16 累积。
- weighted U 冻结 `statistical_unit=microbatch`、`weight_unit=effective_target_tokens`、有放回 product sampling、
  `weights_exogenous=true` 与 `common_mean_assumption=true`；任一统计假设不成立时公开结果自动降级为 `no_unbiasedness_claim`。
- 正式证据包含独立 oracle、生产张量 bundle、S1/S2/G1/G2/N1/N2、联合重哈希仍无法绕过的离线 replay、
  120 行逐张量误差、三条实现路线对独立 oracle 的 36 行散点、12 行 raw/U 缩放及 12 行负 U 表。
- 主代理发现并修正最后同步中的三个缺口：旧 schema 仍限制为 14 比较/9 拒绝、离线 replay 未真正使用排列输入、
  scaling SVG 未绘制 U core/score。修正后 schema 为 20/14 精确闭集，replay 使用 reverse/rotate 的真实样本—权重配对，
  SVG 由 CSV 精确投影五类柱。
- S1.4 handoff 采用“历史角色/自哈希严格验证 + 当前代码语义重建”策略：仅允许 S1.5 合法修改的
  `core/__init__.py` 与 `stage01_task_runners.py` 两个共享文件发生 source digest 漂移，其他上游文件漂移直接拒绝；
  重建时除 source/self/cross hash 外的 report、table、gate 全字段必须与正式 S1.4 证据一致。
- 实现与正式 producer/consumer commit：`c7f10f4e2f8bbbbe6bc459f8b95938bcd620cbff`。
- 本地受控验收：S1.5 正式回归精确集合 `57 passed`；S1.1–S1.5 受影响跨阶段集合 `139 passed`；
  5 个生成角色和冻结 fixture 通过 Draft 2020-12 实例验证，8 份 schema 通过 schema 自检；
  `compileall` 与 `git diff --check` 均通过。
