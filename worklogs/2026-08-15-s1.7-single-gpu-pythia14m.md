## 任务边界

- 任务：`stage1.07_single_gpu_pythia14m`。
- 上游：S1.6 `G1-STEP` 正式 index
  `evidence/stage1/s1-6-formal/ceb202ec3278c60111a31d82692b36eb98de6a40/formal-20260815-s16-v1-r3/index.json`，
  文件 SHA-256 为 `9b25d016bdfb82a75d46b3fa89432211314e72e9a63522c772c2da1a764e69bc`，
  Gate artifact hash 为 `872775ca7b74d5948019bb47ee070ec5f5cf81dc2127ca16d805944787a61a64`。

  raw/double/显式 U/流式 U、两步统计开关对照、参数 registry、长期累计量、资源边界、网络 guard、
  GPU UUID 租约与正式产物发布；本任务只证明正确性和可复现性，不解释参数分布或训练现象。

- 大数组不进入 JSON 或 pickle；正式 safetensors manifest 逐张量绑定 name、shape、dtype、SHA-256、
  phase map 与 registry。所有 JSON 均使用规范序列化和自哈希，成功前才原子发布正式目录。

## 不可变失败尝试与修正

所有失败 attempt 都保留在 `$DATA_ROOT/tmp/stage1-s1-7/`，没有覆盖、删除或冒充正式 evidence；
`r1`–`r10` 均未产生成功 target。

- `r1`：Windows 与服务器 Git 对 binary diff 的 abbreviated object-id 长度不同，导致同一语义 patch
  字节哈希漂移。提交 `a249a56ffa807e65f38066203240e36eb0e780d9` 改用 `git diff --full-index`，
  冻结三文件 canonical patch SHA-256
  `308db1c1e38135e5a65d37fa92566ac9cd5136220b4ffbb143a7e2f323d1ee0`。
- `r2`：历史 G3 replay 从不存在的 `metadata.storage.idx.size_bytes` 读取 Pile 大小。提交
  `ecb210610130e1a776b25bc2a7564e9e4dd25fff` 改为严格读取 READY manifest 的两个 file descriptor，
  与 resolution `bytes_checked=31,757,184,042` 三方交叉验证。
- `r3`：历史 canonical hash、模型 config vocab、tokenizer runtime 长度与 dropout 活跃字段的身份边界不完整。
  提交 `d271a8de544fd57dbcb5c477721407d9ca865011` 冻结历史 canonical writer、50,304/50,277
  双 vocab 身份及仅 `attention_dropout`、`hidden_dropout` 为 0.0 的合同。
- `r4`：主代理命令误传了缩短且错误的 G3 logical ref，运行在租约前 fail-closed。该项是操作层错误，
  不计作 Gate 结果；原 attempt 保留。
- `r5`：真实资产 provenance 中 model/tokenizer 的 `storage_kind=null`，Pile 为
  `pythia_mmap_shards`。提交 `3eb6172fe979ab83c7616de4dc504c504bc44018` 用角色化 Schema 精确冻结三者。
- `r6`：真实 Torch 2.12.1 AdamW 的 `betas` 是 tuple，不能直接规范 JSON 哈希。提交
  `8ac4250e45ad14d3df307e3001e34c1cebeee31f` 冻结唯一参数组、12 个 group key、稳定参数名顺序、
  canonical betas list，以及 `step/exp_avg/exp_avg_sq` 的 dtype、device、layout、stride 合同。
- `r7`：TrainingEngine 达到两步上限时终态为 `COMPLETE`，不是 `PASS`。提交
  `7362281741b3a280eecc51b60d78d9e3a35b36a8` 精确绑定 COMPLETE、两次 attempt、零 skip、
  两条 COMMITTED record、8,192 effective tokens 和 `s17:train-*` batch IDs。

  `14a7cb5590093d9bf31308847f029745c6e6c33b` 冻结统计关闭为 null，clip=1 为
  `local_gradient_space_importance_u_weighted`，clip<1 为
  `local_gradient_space_importance_u_clipped`，并由 worker、formalizer、Schema 独立交叉验证。
- `r9`：GPU、数组、oracle、图表和负例均完成后，历史 G3 replay 因旧脚本用 `json.dumps` 且无唯一尾随 LF

  提交 `92423c92f927c847a083cf063c7f22d463ce9f63` 冻结设备名
  `NVIDIA A100-SXM4-80GB`。随后主代理不再申请 GPU，而是用 r10 的七个真实持久化角色逐项重放 Schema，
